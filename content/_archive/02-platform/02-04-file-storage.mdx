## 1. Purpose

Where every uploaded file in the platform lives: CVs, registration certificates, ID scans, WhatsApp
voice notes, signed offers, statutory forms, invoices and payslips. One store, one upload control, one
viewer, one retention rule — and one guarantee that nothing leaves the Mumbai region, which is what
makes the DPDP position hold.

## 2. Scope

### In scope

- Storage of every file uploaded anywhere in the platform, with versions
- Virus scanning before a file becomes available; quarantine on failure
- The upload control and file viewer other screens drop in
- Expiring download links — a shared link does not stay open indefinitely
- Mumbai-only residency, backups included
- Retention rule per document type, applied by `02-12`

### Explicitly out of scope

- Reading the content of a file. CV parsing is `03-05`/`04-06`, credential OCR is `04-10`,
  spreadsheet parsing is `03-02`. This component stores and serves; it never interprets.
- Document review workflow (`M4-I14`) — that belongs to `03-04`.
- Generating documents. Offers are rendered by `03-08`, invoices by `03-11`, payslips by `03-17`;
  each hands the rendered file here.

### Explicitly not built

- A general document management system: folders, sharing, collaborative editing, search inside files.
- Client-facing file browsing before Phase 6.
- Digital signature. That is `04-11`, which stores its signed output here.

## 5. Data model

```sql
CREATE TABLE files.document (
    id            uuid PRIMARY KEY DEFAULT uuidv7(),
    document_type text NOT NULL,        -- 'cv' | 'registration_certificate' | 'id_proof'
                                        -- | 'voice_note' | 'signed_offer' | 'invoice' | 'payslip' …
    owner_type    text NOT NULL,        -- 'candidate' | 'client' | 'placement' | 'inbound_record' …
    owner_id      uuid NOT NULL,
    current_version integer NOT NULL DEFAULT 1,
    status        text NOT NULL DEFAULT 'uploaded'
                    CHECK (status IN ('uploaded','scanning','available','quarantined')),
    retention_policy text NOT NULL,     -- resolved by 02-12
    created_at timestamptz NOT NULL DEFAULT now(), created_by uuid NOT NULL,
    updated_at timestamptz NOT NULL DEFAULT now(), updated_by uuid NOT NULL
);
CREATE INDEX ON files.document (owner_type, owner_id, document_type);

CREATE TABLE files.document_version (
    id            uuid PRIMARY KEY DEFAULT uuidv7(),
    document_id   uuid NOT NULL REFERENCES files.document(id),
    version       integer NOT NULL,
    s3_key        text NOT NULL,        -- ap-south-1 bucket, SSE-KMS
    content_type  text NOT NULL,
    size_bytes    bigint NOT NULL,
    checksum_sha256 text NOT NULL,
    scan_status   text NOT NULL DEFAULT 'pending'
                    CHECK (scan_status IN ('pending','clean','infected','failed')),
    scanned_at    timestamptz,
    uploaded_at   timestamptz NOT NULL DEFAULT now(),
    uploaded_by   uuid NOT NULL,
    superseded_at timestamptz,          -- replacing keeps the previous version
    UNIQUE (document_id, version)
);

CREATE TABLE files.download_grant (     -- every expiring link that was issued
    id uuid PRIMARY KEY DEFAULT uuidv7(),
    document_version_id uuid NOT NULL REFERENCES files.document_version(id),
    issued_to_type text NOT NULL,       -- 'staff' | 'candidate' | 'client_user' | 'link'
    issued_to_id   uuid,
    expires_at timestamptz NOT NULL,
    used_at timestamptz,
    issued_at timestamptz NOT NULL DEFAULT now()
);
```

Bucket policy: block all public access; SSE-KMS with a dedicated key; versioning on; no replication
outside `ap-south-1`; lifecycle rules driven by `retention_policy`.

## 6. State machines

### `Document`

| From | Event | To | Rule |
|---|---|---|---|
| — | presigned upload completes | `uploaded` | Not yet readable by anyone |
| `uploaded` | `edge-object-created` fires | `scanning` | |
| `scanning` | scan clean | `available` | Only now can it be downloaded or rendered |
| `scanning` | scan infected or failed | `quarantined` | Owner is notified; the uploader may replace it |
| `available` | replacement uploaded | `available` (version + 1) | **The previous version is retained, not overwritten** |
| any | retention period reached | deleted or pseudonymised by `02-12` | Subject to `OI-HS-02`, `OI-HS-14` |

A `quarantined` document is never served, never parsed, and never counts towards a completeness check.

## 7. API surface

| Method | Path | Permission | Purpose |
|---|---|---|---|
| `POST` | `/v1/documents/upload-url` | owner-dependent | Returns a presigned S3 PUT plus the `documentId` — files never pass through the API |
| `POST` | `/v1/documents/:id/complete` | owner-dependent | Marks the upload finished; scanning begins |
| `GET` | `/v1/documents/:id` | owner-dependent | Metadata, versions, status |
| `GET` | `/v1/documents/:id/download-url` | owner-dependent | **Short-lived** presigned GET, recorded as a `download_grant` |
| `GET` | `/v1/documents/:id/versions` | owner-dependent | Version history |
| `POST` | `/v1/documents/:id/replace` | owner-dependent | New version; previous retained |

Permission is delegated: `files` asks the owning component whether this principal may see this owner's
documents. A `link` principal may fetch only documents attached to the single record its token covers.

Errors: `409` document not yet `available`; `410` grant expired; `413` over the size limit; `415`
disallowed content type.

## 8. Events and jobs

**Events emitted**

| Event | When | Consumed by |
|---|---|---|
| `files.document.available` | scan clean | `04-10` OCR, `04-06` CV parsing, `03-04` verification |
| `files.document.quarantined` | scan failed | `02-09` notifies the uploader |
| `files.document.replaced` | new version | `03-04` re-verification prompt |

**Jobs**

| Job | Trigger | Purpose |
|---|---|---|
| `files.scan` | `edge-object-created` Lambda | ClamAV scan, sets `scan_status` |
| `files.retention-sweep` | weekly, from `02-12` | Applies the retention policy per document type |
| `files.orphan-sweep` | daily | Removes uploads never completed within 24h |

| # | Criterion | Traces to |
