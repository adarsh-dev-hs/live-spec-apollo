## 1. Purpose

The source system for the A10 migration: Apollo's existing candidate data, held in CPAL and current
tooling. Once the migrated data reconciles, **the platform becomes the system of record and CPAL is
switched off.**

**Nobody has seen this data.** Volume, completeness, duplicate rate and field mappability are all
unknown, which is why every figure attached to A10 is a placeholder.

## 2. Scope

**In scope:** read access to the source; extraction into the staging tables; the mapping definition;
delta extraction between the main load and cutover; a lineage reference from every loaded record back
to its source record.

**Explicitly out of scope:** the migration pipeline, screens and reconciliation (`03-13`); duplicate
merging (`03-04` owns the merge, `03-13` calls it); cutover and retirement (`05-05`).

**Explicitly not built:** two-way sync; writing anything back to CPAL; migrating clients, contracts or
rate cards — nothing in the plan scopes those.

## 3. Plan traceability

Effort sits in `03-13` (`M1-I10`, `M1-I11`). This file specifies the source-side contract and what is
unknown about it.

## 4. Dependencies

**Must exist first:** nothing in the codebase. **Access is the dependency.**

**Consumed by:** `03-13`, and therefore `03-04`'s candidate base at go-live.

**External:** `X20` — **legacy ATS data access, month 1.** *"The single largest unpriced item in the six
months. Until profiling runs we do not know how many records there are, how complete they are or how
many duplicates exist, so none of the migration can be estimated."*

## 5. Data model

Source shape **unknown**. The extraction contract is deliberately minimal so that whatever arrives can
be staged before it is understood:

```ts
interface LegacySource {
  extract(i: { since?: string; cursor?: string }): Promise<{
    records: Array<{ sourceRef: string; payload: Record<string, unknown>; updatedAt?: string }>
    cursor?: string
    total?: number                              // may be unavailable
  }>
  listDocuments(sourceRef: string): Promise<Array<{ name: string; url: string }>>
}
```

`migration.record.source_payload` stores **exactly what was extracted**, before any mapping, so a
mapping mistake is recoverable without re-extracting.

## 6. State machines

`migration.batch` and `migration.record` (`03-13`). Source-side: **extraction is resumable by cursor**,
because a source that cannot report a total also cannot be assumed to be stable mid-read.

## 7. API surface

**N/A** — extraction is a job, not an endpoint. If CPAL exposes no API, extraction is a database read or
a file drop; **which one is unknown until access is granted**, and the contract above is satisfiable by
any of the three.

## 8. Events and jobs

`migration.load` and `migration.delta` (`batch` class, `03-13`), checkpointed and resumable.
