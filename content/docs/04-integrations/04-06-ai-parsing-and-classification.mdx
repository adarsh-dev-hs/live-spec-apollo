## 1. Purpose

Four jobs done by one model layer: decide whether an inbound message is a demand or a candidate
response, extract requisition fields from free text and transcripts, read a CV into profile fields, and
turn a free-text or spoken availability answer into a structured payload.

Accuracy here **directly sets the manual-entry queue load**, which is an operational figure as much as a
technical one — and the confidence threshold is agreed **once, shared across A1 and A14**, not tuned per
consumer.

## 2. Scope

**In scope:** the model interface and prompt/schema definitions; intent classification with a shared
threshold; field extraction to the requisition schema; CV extraction with **per-field confidence**;
availability answer extraction; inference cost recording; the fixture set that measures accuracy.

**Explicitly out of scope:** the pipeline that routes results (`02-08`); the queues where humans fix
things (`03-02`, `03-06`); spreadsheet mapping, which is deterministic (`04-08`); HRMS payloads, which
are already structured and **skip parsing entirely**.

**Explicitly not built:** **retraining or continuous learning** — a configured threshold is applied;
model-driven ranking (`03-07` is deterministic scoring); a prompt-editing UI.

## 4. Dependencies

**Must exist first:** `02-08`, `02-03` (the threshold lives here as a setting), `03-04` (the category
attribute schema extraction targets), `02-10`.

narrows the field considerably and is a selection criterion, not a preference.

## 5. Data model

No tables. `inbound.classification` records confidence and who decided; `demand.parse_result` records
extraction with per-field confidence and **unmapped content retained**; `candidates.cv_parse` records
the machine value alongside what the candidate corrected, **so accuracy is measurable**.

```ts
interface AiProvider {
  classifyIntent(i: { text: string; registeredIntents: string[] })
    : Promise<{ intent: string; confidence: number; costUnits: number }>
  extractFields(i: { text: string; targetSchema: JsonSchema })
    : Promise<{ values: Record<string, unknown>; fieldConfidence: Record<string, number>;
                unmapped: Record<string, unknown>; costUnits: number }>
}
```

## 6. State machines

**N/A** — stateless calls. The states they drive belong to `02-08`'s `InboundRecord` and `03-06`'s
`AvailabilityResponse`. One rule governs all four uses: **below the shared threshold, a human decides;
nothing is written back on low confidence.**

## 7. API surface

In-process only: `ai.classifyIntent()`, `ai.extractFields()`. No public endpoint, and no module calls a
model directly.

## 8. Events and jobs

`inbound.classify`, `demand.parse`, `candidates.parse-cv`, `engagement.extract-voice-answer` — all on
the `provider` queue class with inference cost recorded per call.

## 9. Frontend

**N/A** — the threshold is edited in `02-03`; correction happens in `03-02`'s manual entry queue,
`03-04`'s document review, `03-05`'s CV review and `03-06`'s reply review.
