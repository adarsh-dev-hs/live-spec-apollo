**Package** `@apollo/integration-stt` · **Schema** `inbound` · **Plan** A1 · **Effort** ~11.0pd · **Risk** High `EXT` · **Build in** Phase 3

## 1. Purpose

Clients send vacancies as WhatsApp voice notes. This turns the audio into text so it can be parsed to
the same requisition schema as WhatsApp text — and **keeps the audio playable** so a recruiter can
listen when the machine could not read it.

The audio is recorded in a hospital corridor, not a studio. **Language coverage must be proven against
field-captured audio**, not sample files.

## 2. Scope

**In scope:** transcribing an audio payload; language detection and coverage; retaining audio against
the inbound record; routing failures and over-length notes to manual entry with audio intact;
per-minute cost recording.

**Explicitly out of scope:** parsing the transcript into fields (`03-02`); the manual entry queue
(`03-02`); voice **calls** (`04-04`).

**Explicitly not built:** speaker diarisation; transcription of trial check-in calls (`04-04` returns
its own transcript); a transcription review screen beyond the manual entry queue.

## 5. Data model

No tables. `inbound.inbound_record.transcript` holds the text; `raw_document_id` points at the audio in
`02-04`.

```ts
interface SpeechToTextProvider {
  transcribe(i: { documentId: string; languageHints: string[] }): Promise<{
    text: string; detectedLanguage: string; confidence: number; durationSeconds: number; costUnits: number
  }>
}
```

## 6. State machines

Within `02-08`'s `InboundRecord`: `identified → parsed` on success;
`identified → unparseable` on transcription failure **with the audio retained and playable**, and the
same for a note beyond the accepted duration — **routed to manual entry rather than rejected**.

## 7. API surface

In-process `stt.transcribe()`, called by the `inbound.classify` pipeline. No public endpoint.

## 8. Events and jobs

`stt.transcribe` on the `provider` queue class, rate-limited, cost recorded.

## 9. Frontend

**N/A** — the audio player and transcript appear in `03-02`'s manual entry queue, built from `02-04`'s
`<FileViewer>`.
