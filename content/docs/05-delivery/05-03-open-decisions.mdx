## 7. How to close one

1. Get the decision from the named owner, in writing, at a gate or in a written record.
2. Update this register: the row moves to a **Closed** table below with the decision and the date.
3. Update every spec §11 that references it, and the §5/§6/§10 sections the decision changes.
4. If the decision **contradicts a working assumption**, search for the `AS-` reference — it is applied
   in more than one place by design, and all of them move together.
5. If it changes scope rather than a number — `OI-A-13` is the live example — it is a **change**, not a
