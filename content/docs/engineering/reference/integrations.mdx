Fifteen external systems. **Only a third have a named supplier.** Each unnamed supplier is an
unpriced integration and a failure mode nobody can test against, which is why every one of them sits
behind an interface with a manual fallback.

## 2. The rules every integration obeys

1. **Behind an interface.** No provider name appears in domain logic. Replacing a supplier is a new
   adapter, not a change to a module.
2. **A manual fallback exists.** Every path degrades to something a person can work with. **No
   provider failure is allowed to fail a candidate, lose a payload, or silently stop a business
   chain.**
3. **The raw payload is written down first.** Whatever arrives is persisted before anything tries to
   understand it, and it is kept.
4. **Redelivery is normal.** Every inbound path deduplicates on the provider's message id.
5. **Cost is attributed.** Every provider call records its consumption units against a cause, because
   the running-cost figure Apollo has asked for cannot be reconstructed afterwards.
6. **A contract test per adapter.** A core change that breaks an existing adapter fails the build.
7. **Where no supplier is named**, the integration ships with a stub adapter plus a contract test, and
   the missing fixture set is recorded as a named gap rather than assumed away.

## 3. What happens when one fails

| Failure | What the platform does |
|---|---|
| WhatsApp provider down | Sends queue and retry; **the inbound webhook still records the payload** |
| WhatsApp template not yet approved | **The send is refused, not attempted** — the template carries its approval state |
| SMS template rejected by the registry | Falls back to the next channel in the trigger's order |
| Email service still sandboxed | Only verified addresses receive mail. **Looks like a product failure, is a configuration one** |
| Voice call unanswered | Retries per campaign policy, inside the call window and frequency caps |
| Voice or text extraction below the confidence threshold | Review queue. **Never a silent confidence reset** |
| Transcription fails, or the note is over length | Manual entry, **with the audio retained and playable** — not rejected |
| AI provider outage | Inbound records still written, classification retried, nothing discarded |
| Client system tenant unresolvable | Unmatched queue, for manual selection |
| A spreadsheet row fails mapping | **Named row-level error; the valid rows still produce requisitions** |
| A council has no API | **Document plus manual verification behind the same interface** |
| Verification aggregator outage | Manual fallback — **never fails the candidate**; surfaces as awaiting-registry pendency |
| Document reading fails | Manual entry, with the document retained |
| E-signature provider down | The offer stays sent; signature status updates when the provider returns |
| App store rejection | **Calendar risk no team size removes.** A placeholder build goes through review early |
| Finance system not yet named | Generic API and file export; **a re-export does not duplicate in the target** |
| Payroll engine rejects a person | Reported with the engine's reason, correctable and resendable |
| A legacy record will not map | Exception queue; corrected or rejected **with a reason, never lost** |

## 4. Metered cost

Apollo has asked for consumption volumes per requisition across messaging, email and transcription so
running costs can be modelled.

| Metered | Unit | Set by |
|---|---|---|
| WhatsApp | Per conversation | Cadence configuration and follow-up frequency |
| Voice | Per minute | Campaign window and retry policy |
| Transcription | Per minute | How many clients send voice notes |
| Document reading | Per page | Candidate intake volume |
| Verification | Per check | Which attributes are configured per category |
| AI inference | Per inbound message | Intake volume, and classification accuracy |

**The answer runs both ways.** Apollo needs a cost figure from the Service Provider, and the Service
Provider needs Apollo's expected base size and contact frequency to produce one. Until both exist,
every cadence screen shows a projected volume and cost before the cadence can be enabled.
